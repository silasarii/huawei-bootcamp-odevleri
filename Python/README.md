# 🐍 Python Temelleri ve Uygulamaları

Bu klasör, **Huawei Student Developers** ve **Türkiye Yapay Zeka Akademisi** iş birliğiyle düzenlenen Veri Bilimi ve Makine Öğrenmesi Bootcamp'inin 1. haftası kapsamında tamamlanan Python ödevlerini, mini projeleri ve temel veri bilimi kütüphaneleri uygulamalarını içermektedir.

---

## 📂 İçerik ve Dosya Yapısı

Aşağıda klasör içerisinde yer alan Jupyter Notebook dosyaları ve içerdiği konular listelenmiştir:

| Dosya Adı | Konu / Açıklama |
| :--- | :--- |
| `02_temel_yapilar_odev.ipynb` | Python temel veri tipleri (string, int, float, list, dict, set, tuple) ve değişkenler ile ilgili alıştırmalar. |
| `03_donguler_kontrol_yapilari_odev.ipynb` | `if-elif-else` koşullu durumları, `for` ve `while` döngüleri, karar mekanizmaları. |
| `04_fonksiyonlar_mini_proje.ipynb` | Modüler kod yazımı, fonksiyon tanımlama, parametre kullanımı ve `return` mekanizmaları içeren mini proje. |
| `05_dosya_islemleri_odev.ipynb` | Metin/veri dosyalarını okuma (`read`), yazma (`write`), ekleme (`append`) ve dosya yönetimi işlemleri. |
| `06_hata_yonetimi_mini_proje.ipynb` | `try-except-finally` blokları, istisna (exception) yönetimi ve özel hata fırlatma (`raise`) çalışmaları. |
| `08_numpy_odev.ipynb` | Multi-dimensional diziler (ndarray), vektörel işlemler, indexing, slicing ve matematiksel/istatistiksel fonksiyonlar. |
| `09_pandas_odev.ipynb` | Series ve DataFrame yapıları, veri okuma, filtreleme, gruplama (`groupby`), birleştirme (`merge/concat`) ve veri manipülasyonu. |
| `10_matplotlib_odev.ipynb` | Veri görselleştirme: Çizgi (line), sütun (bar), saçılım (scatter) grafikleri ve grafik özelleştirme adımları. |
| `11_nesne_yonelimli_mini_proje.ipynb` | Nesne Yönelimli Programlama (OOP) ilkeleri: Sınıf (Class), Nesne (Object), Kalıtım (Inheritance) ve Metot kullanımı. |
| `12_ogrenci_not_analizi_projesi.ipynb` | **1. Hafta Bitirme Projesi:** Python, Pandas ve Matplotlib kullanılarak öğrenci not verilerinin analizi, istatistiklerinin çıkarılması ve görselleştirilmesi. |
